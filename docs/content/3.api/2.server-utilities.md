Server utilities are available inside Nitro event handlers via auto-imports (`#imports`) or explicit imports from `nuxt-box-sdk/server`. They run exclusively on the server and are never bundled into the client.

---

## Get a Server-Side Client

### `useBoxClient(auth?, session?)` — server

Returns a `BoxClient` configured for a Nitro event handler. Automatically wires server-side token storage and resolves the auth strategy from `runtimeConfig`.

**Signatures**

```typescript
import type { Authentication, NetworkSession } from 'box-node-sdk/networking'
import type { BoxNetworkOptions } from '#nuxt/box-sdk/types'

function useBoxClient<T extends Authentication>(
  auth?: T,
  session?: NetworkSession | BoxNetworkOptions
): BoxClient<T>

function useBoxClient<T extends BoxAuthType>(
  auth?: T,
  authConfig?: UseBoxAuthConfigInput<T>,
  session?: NetworkSession | BoxNetworkOptions
): BoxClient<UseBoxAuthReturns<T>>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth` | `Authentication \| BoxAuthType` | No | Explicit auth instance or auth type string (`'ccg'`, `'jwt'`, `'oauth'`, `'dev'`). Falls back to module config. |
| `authConfig` | `UseBoxAuthConfigInput<T>` | No | Auth config when `auth` is a type string. |
| `session` | `NetworkSession \| BoxNetworkOptions` | No | Custom network session or options object. Accepts `asUser`, `suppressNotifications`, `additionalHeaders`, `baseUrls`. |

**Returns** `BoxClient`

**Example**

```typescript
// server/api/files/[id].get.ts
export default defineEventHandler(async (event) => {
  const client = useBoxClient()
  const file = await client.files.getFileById(event.context.params!.id)
  return file
})
```

### `useBoxCcgClient(authConfig?, session?)`

Returns a `BoxClient` authenticated via Client Credentials Grant.

**Signature**

```typescript
function useBoxCcgClient(
  authConfig?: UseBoxAuthConfigInput<'ccg'>,
  session?: NetworkSession | BoxNetworkOptions
): BoxClient<BoxCcgAuth>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `authConfig` | `CcgConfigInput` | No | CCG config override. Uses `runtimeConfig.box.ccg` when omitted. |
| `session` | `NetworkSession \| BoxNetworkOptions` | No | Custom network session options. |

**Returns** `BoxClient<BoxCcgAuth>`

**Example**

```typescript
// server/api/enterprise/users.get.ts
export default defineEventHandler(async (_event) => {
  // Reads NUXT_BOX_CCG_* env vars automatically
  const client = useBoxCcgClient()
  return client.users.getUsers()
})
```

### `useBoxJwtClient(authConfig?, session?)`

Returns a `BoxClient` authenticated via JWT (Service Account).

**Signature**

```typescript
function useBoxJwtClient(
  authConfig?: UseBoxAuthConfigInput<'jwt'>,
  session?: NetworkSession | BoxNetworkOptions
): BoxClient<BoxJwtAuth>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `authConfig` | `JwtConfigInput` | No | JWT config override. Alternatively, provide `{ configFile: 'path/to/config.json' }` or `{ configJson: '...' }`. Uses `runtimeConfig.box.jwt` when omitted. |
| `session` | `NetworkSession \| BoxNetworkOptions` | No | Custom network session options. |

**Returns** `BoxClient<BoxJwtAuth>`

**Example**

```typescript
// server/api/folders/index.post.ts
export default defineEventHandler(async (_event) => {
  const client = useBoxJwtClient()
  return client.folders.createFolder({ name: 'New Folder', parent: { id: '0' } })
})
```

### `useBoxOAuthClient(authConfig?, session?)`

Returns a `BoxClient` using OAuth tokens stored for the current user session. Reads the token from Nitro unstorage via `useBoxTokenStorage`.

::note
This client is suitable when users have completed the OAuth flow via `/_box/authenticate`. The stored access token is retrieved automatically using the configured token storage mount.
::

**Signature**

```typescript
function useBoxOAuthClient(
  authConfig?: UseBoxAuthConfigInput<'oauth'>,
  session?: NetworkSession | BoxNetworkOptions
): BoxClient<BoxOAuth>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `authConfig` | `OAuthConfigInput` | No | OAuth config override. Uses `runtimeConfig.box.oauth` when omitted. |
| `session` | `NetworkSession \| BoxNetworkOptions` | No | Custom network session options. |

**Returns** `BoxClient<BoxOAuth>`

**Example**

```typescript
// server/api/me.get.ts
export default defineEventHandler(async (event) => {
  const client = useBoxOAuthClient()
  return client.users.getUserMe()
})
```

## Manage Token Storage

### `useBoxTokenStorage(storage?, options?)`

Returns a `TokenStorage` implementation backed by Nitro's `unstorage`. Tokens are stored under the key `box:{authType}:access_token` by default. The key can be overridden via the `box:token:storageKey` Nitro hook.

**Signature**

```typescript
function useBoxTokenStorage(
  storage?: string | Storage,
  options?: BoxTokenStorageOptions
): TokenStorage
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storage` | `string \| Storage` | No | Storage mount name (e.g. `'cache'`, `'redis'`) or a raw `unstorage` instance. Defaults to `'cache'`. |
| `options` | `BoxTokenStorageOptions` | No | Additional options — see table below. |

**`BoxTokenStorageOptions`**

| Property | Type | Description |
|----------|------|-------------|
| `auth` | `string` | Auth type prefix used to namespace the storage key (e.g. `'ccg'`, `'oauth'`). Defaults to `runtimeConfig.public.box.auth`. |
| `getKey` | `() => string \| Promise<string>` | Custom key resolver. When provided, overrides the default `box:{auth}:access_token` key. |

**Returns** `TokenStorage`

**Example — custom Redis-backed token storage**

```typescript
// server/plugins/box-storage.ts
export default defineNitroPlugin((nitroApp) => {
  // Use a 'redis' storage mount defined in nuxt.config.ts nitro.storage
  const storage = useBoxTokenStorage('redis', { auth: 'oauth' })

  // Attach to the box server plugin context for use in handlers
  nitroApp.hooks.hook('request', (event) => {
    event.context.$box = {
      resolveTokenStorage: () => storage
    }
  })
})
```

## Register Nitro Hooks

The module fires Nitro hooks at key points in the OAuth flow and token lifecycle. Register them inside a Nitro plugin at `server/plugins/box-hooks.ts`.

### Available Hooks

| Hook | Payload | Trigger |
|------|---------|---------|
| `box:login:before` | `{ event: H3Event, options: { redirectUri: string } }` | Fires before the OAuth authorize redirect. Mutate `options` to change the redirect URI or add custom parameters. |
| `box:login:success` | `{ event: H3Event, response: AccessToken }` | Fires after the OAuth token exchange succeeds. `response` contains the new access token. Use this hook to store the token in your own session system. |
| `box:token:storageKey` | `{ auth: string, key: string }` | Fires when the module resolves the unstorage key for token persistence. Mutate `key` to override where the token is stored. |

### Register Hooks in a Nitro Plugin

```typescript
// server/plugins/box-hooks.ts
export default defineNitroPlugin((nitroApp) => {
  // Customize the OAuth redirect URI
  nitroApp.hooks.hook('box:login:before', ({ event, options }) => {
    const requestUrl = getRequestURL(event)
    options.redirectUri = `${requestUrl.origin}/auth/box/callback`
  })

  // Handle the token after OAuth completes
  nitroApp.hooks.hook('box:login:success', async ({ event, response }) => {
    // Store the token in your own session (e.g., via h3 setCookie)
    setCookie(event, 'box_token', response.accessToken!, {
      httpOnly: true,
      secure: true,
      maxAge: response.expiresIn
    })
  })

  // Override the unstorage key per auth type
  nitroApp.hooks.hook('box:token:storageKey', ({ auth, key }) => {
    // e.g. namespace by user ID from a request-scoped context
    if (auth === 'oauth') {
      key.value = `user:${event.context.userId}:box_token`
    }
  })
})
```

::note
The `box:token:storageKey` hook receives the `key` property by reference inside the object — mutate `obj.key`, not a destructured local variable, to take effect.
::

## TypeScript Types

### From `#nuxt/box-sdk/types`

These types are exported from the module's virtual module and are available in all contexts (client, server, and shared).

#### `BoxAuthType`

The union of supported authentication strategies.

```typescript
type BoxAuthType = 'dev' | 'ccg' | 'jwt' | 'oauth'
```

#### `BoxSdkOptions`

The full module options type, matching the `box` key in `nuxt.config.ts`.

```typescript
interface BoxSdkOptions {
  /** Active auth strategy. Set via NUXT_PUBLIC_BOX_AUTH. */
  auth?: BoxAuthType

  /** Named auth resolvers for multi-tenant scenarios. */
  auths?: {
    [name: string]: {
      name?: string
      resolver: (event?: H3Event) => Authentication
    }
  }

  /** Client Credentials Grant config. Set via NUXT_BOX_CCG_*. */
  ccg?: BoxCcgConfig

  /** Developer token (dev mode only). Set via BOX_DEVELOPER_TOKEN. */
  developer?: BoxDeveloperTokenConfig

  /**
   * JWT auth config. Set via NUXT_BOX_JWT.
   * Also accepts { configFile: 'path.json' } or { configJson: '...' }.
   */
  jwt?: BoxJwtConfig | { configJson: string | JwtConfigFile } | { configFile: `${string}.json` }

  /** Manager tree-shaking options. */
  managers?: {
    /** Whether to generate client composables. Default: true. */
    composables?: boolean
    /** Allowlist of manager names to include. */
    include?: Array<BoxManagerNames>
    /** Denylist of manager names to exclude. */
    exclude?: Array<BoxManagerNames>
  }

  /** OAuth 2.0 config. Set via NUXT_BOX_OAUTH_*. */
  oauth?: BoxOAuthConfig
}
```

#### `BoxManager<T, Extends?>`

The extended manager type returned by all `useBox{Manager}Manager` composables. Combines native SDK manager methods with the `ExtendedManager` interface.

```typescript
type BoxManager<
  T extends BoxManagerClass,
  Extends extends { [key: PropertyKey]: any } = {}
> = ExtendedManager & Extends & InstanceType<T>
```

#### `ExtendedManager`

The interface that augments every generated manager composable with network session and async data helpers.

```typescript
interface ExtendedManager extends Pick<NetworkSession,
  'withProxy' | 'withInterceptors' | 'withNetworkClient' |
  'withRetryStrategy' | 'withCustomBaseUrls' | 'withCustomAgentOptions'
> {
  withAsUserHeader: (userId: string) => this
  withExtraHeaders: (extraHeaders?: Record<string, string>) => this
  withSuppressedNotifications: () => this
}
```

#### `BoxNetworkOptions`

A plain-object alternative to `NetworkSession` accepted by server client factories.

```typescript
interface BoxNetworkOptions {
  asUser?: string
  baseUrls?: BaseUrlsInput
  suppressNotifications?: boolean
  additionalHeaders?: Record<string, string>
  // ...other NetworkSessionInput fields
}
```

### From `box-node-sdk/box`

Import these types directly from the SDK subpath when you need to construct auth configs manually.

| Type | Description |
|------|-------------|
| `CcgConfigInput` | Raw input for Client Credentials Grant configuration. |
| `JwtConfigInput` | Raw input for JWT configuration. |
| `OAuthConfigInput` | Raw input for OAuth 2.0 configuration. |
| `DeveloperTokenConfig` | Developer token configuration shape. |
| `JwtConfigFile` | Parsed JWT config file structure (from Box app settings JSON). |
| `TokenStorage` | Interface for custom token persistence implementations. |
| `InMemoryTokenStorage` | Built-in in-memory `TokenStorage`. |
| `BoxSdkError` | Base error class thrown by the Box SDK. |

**Import example**

```typescript
import type { CcgConfigInput, TokenStorage } from 'box-node-sdk/box'
import { InMemoryTokenStorage, BoxSdkError } from 'box-node-sdk/box'
```
