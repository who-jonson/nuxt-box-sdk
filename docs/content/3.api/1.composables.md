All composables listed here are **auto-imported** by `nuxt-box-sdk`. You do not need to import them manually in your Vue files or universal composables. Manager composables are generated at build time — only managers listed in `managers.include` (or all managers not in `managers.exclude`) are bundled.

---

## Use a Box Client

### `useBoxClient(auth?, networkSession?)`

Returns a `BoxClient` instance configured from module options. On the client side, when proxy mode is active (`ssr: true` and `proxy` is set), the client automatically routes requests through the proxy base URL.

**Signatures**

```typescript
function useBoxClient<T extends Authentication>(auth?: T): BoxClient
function useBoxClient<T extends TokenStorage>(tokenStorage?: T): BoxClient
function useBoxClient<T extends string | AccessToken>(token?: T, config?: BoxTokenAuthConfig): BoxClient
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth` | `Authentication \| TokenStorage \| string \| AccessToken` | No | Explicit auth instance, token storage, raw access token string, or `AccessToken` object. When omitted, the module config is used. |
| `config` | `BoxTokenAuthConfig` | No | Optional `{ clientId, clientSecret }` when passing a raw token. |

**Returns** `BoxClient`

**Example**

```vue
<script setup lang="ts">
// No arguments — uses module config (or proxy when enabled)
const client = useBoxClient()
const me = await client.users.getUserMe()

// Explicit token
const tokenClient = useBoxClient('my-access-token')
</script>
```

---

### `useBoxBasicClient(fields?)`

Returns a `BoxClient` configured with a developer token. In development mode, falls back to the `developer.token` from `runtimeConfig` when no token is provided in `fields`.

::note
`useBoxBasicClient` is intended for development and testing. Do not use a long-lived developer token in production.
::

**Signature**

```typescript
function useBoxBasicClient(fields?: Omit<BoxTokenAuthOptions, 'config'>): BoxClient
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fields` | `Omit<BoxTokenAuthOptions, 'config'>` | No | `{ token?, tokenStorage? }`. When omitted in dev mode, uses `runtimeConfig.public.box.developer.token`. |

**Returns** `BoxClient`

**Example**

```vue
<script setup lang="ts">
// Uses NUXT_PUBLIC_BOX_DEVELOPER_TOKEN in dev; explicit token in prod
const client = useBoxBasicClient({ token: 'MY_DEV_TOKEN' })
const items = await client.folders.getFolderItems('0')
</script>
```

---

### `createBoxClient(auth?, config?)`

Factory function that creates a `BoxClient` with full control over auth and network options. Unlike `useBoxClient`, it does not cache the result.

**Signature**

```typescript
function createBoxClient(
  auth?: string | AccessToken | TokenStorage | Authentication,
  config?: BoxTokenAuthConfig
): BoxClient
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth` | `string \| AccessToken \| TokenStorage \| Authentication` | No | Auth source. Proxy client is created when omitted and proxy is configured. |
| `config` | `BoxTokenAuthConfig` | No | `{ clientId?, clientSecret? }` — used when `auth` is a raw token string. |

**Returns** `BoxClient`

**Example**

```typescript
// server/utils/box.ts
import { InMemoryTokenStorage } from 'box-node-sdk/box'

const storage = new InMemoryTokenStorage({ token: { accessToken: 'token' } })
const client = createBoxClient(storage)
```

## Use a Manager Composable

### `useBox{Manager}Manager(auth?, networkSession?)`

Build-time generated composables, one per included Box manager. Examples include `useBoxFilesManager`, `useBoxFoldersManager`, `useBoxSearchManager`, `useBoxMetadataManager`, `useBoxWebhooksManager`, `useBoxUsersManager`, and others.

Each composable returns an **extended manager instance** — a standard Box SDK manager augmented with async data helpers and network session utilities.

**Signature**

```typescript
function useBox{Manager}Manager(
  auth?: Authentication | TokenStorage | string | AccessToken,
  networkSession?: NetworkSession
): BoxManager<{Manager}Manager>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth` | `Authentication \| TokenStorage \| string \| AccessToken` | No | Auth override. Uses module config when omitted. |
| `networkSession` | `NetworkSession` | No | Custom network session (base URLs, headers, retry strategy, etc.). |

**Returns** Extended manager instance with all native SDK methods plus the helpers below.

---

#### `.withAsyncData(opts?)`

Returns a Proxy over the manager where every async method is automatically wrapped in Nuxt's `useAsyncData`. The cache key is derived from the method name and its arguments using `ohash`. You can pass an extra options object as the last argument to any wrapped method call to override `useAsyncData` options.

**Signature**

```typescript
manager.withAsyncData(opts?: AsyncDataOptions<any>): InstanceType<WithAsyncData<typeof Manager>>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `opts` | `AsyncDataOptions<any>` | No | Default `useAsyncData` options applied to every call through the Proxy. |

**Example — list folder items reactively**

```vue
<script setup lang="ts">
const folderId = ref('0')

// Every call on this proxy returns AsyncData
const folders = useBoxFoldersManager().withAsyncData()

// Reactive: re-fetches when folderId changes
const { data: items, status } = folders.getFolderItems(folderId)
</script>

<template>
  <div v-if="status === 'success'">
    <p v-for="entry in items?.entries" :key="entry.id">{{ entry.name }}</p>
  </div>
</template>
```

---

#### `.useAsyncData(handler, opts?)`

Calls a method inside `useAsyncData`, passing the manager instance to the handler. The cache key defaults to `box:{ManagerName}:{hash(args)}` when not provided explicitly.

**Signatures**

```typescript
manager.useAsyncData<ResT>(
  handler: (manager: Manager, nuxtApp?: NuxtApp) => Promise<ResT>,
  options?: AsyncDataOptions<ResT>
): AsyncData<ResT, NuxtError>

manager.useAsyncData<ResT>(
  key: string,
  handler: (manager: Manager, nuxtApp?: NuxtApp) => Promise<ResT>,
  options?: AsyncDataOptions<ResT>
): AsyncData<ResT, NuxtError>
```

**Example — get a specific file**

```vue
<script setup lang="ts">
const props = defineProps<{ fileId: string }>()

const { data: file } = useBoxFilesManager().useAsyncData(
  `file-${props.fileId}`,
  manager => manager.getFileById(props.fileId)
)
</script>
```

---

#### `.useLazyAsyncData(handler, opts?)`

Same as `.useAsyncData` but sets `lazy: true` — the data fetch does not block navigation.

**Signatures**

```typescript
manager.useLazyAsyncData<ResT>(
  handler: (manager: Manager, nuxtApp?: NuxtApp) => Promise<ResT>,
  options?: Omit<AsyncDataOptions<ResT>, 'lazy'>
): AsyncData<ResT, NuxtError>

manager.useLazyAsyncData<ResT>(
  key: string,
  handler: (manager: Manager, nuxtApp?: NuxtApp) => Promise<ResT>,
  options?: Omit<AsyncDataOptions<ResT>, 'lazy'>
): AsyncData<ResT, NuxtError>
```

**Example — search results without blocking**

```vue
<script setup lang="ts">
const query = ref('quarterly report')

const { data: results, pending } = useBoxSearchManager().useLazyAsyncData(
  () => `search-${query.value}`,
  manager => manager.searchForContent({ query: query.value })
)
</script>

<template>
  <div>
    <p v-if="pending">Searching…</p>
    <ul v-else>
      <li v-for="item in results?.entries" :key="item.id">{{ item.name }}</li>
    </ul>
  </div>
</template>
```

---

#### `.withAsUserHeader(userId)`

Returns a new manager variant that sends the `As-User` header on every request, acting on behalf of the specified managed user.

**Signature**

```typescript
manager.withAsUserHeader(userId: string): this
```

**Example**

```typescript
const filesManager = useBoxFilesManager().withAsUserHeader('12345678')
const file = await filesManager.getFileById('9876543210')
```

---

#### `.withExtraHeaders(headers)`

Returns a new manager variant that appends custom HTTP headers to every request.

**Signature**

```typescript
manager.withExtraHeaders(headers: Record<string, string>): this
```

**Example**

```typescript
const manager = useBoxFilesManager().withExtraHeaders({
  'X-Request-Id': crypto.randomUUID()
})
```

---

#### `.withSuppressedNotifications()`

Returns a new manager variant that sends the `Box-Notifications: off` header, suppressing Box email notifications triggered by the operations performed.

**Signature**

```typescript
manager.withSuppressedNotifications(): this
```

**Example**

```typescript
// Bulk-delete files without triggering notification emails
const manager = useBoxFilesManager().withSuppressedNotifications()
await manager.deleteFileById('111')
await manager.deleteFileById('222')
```

## Use Auth

### `useBoxAuth(options?)`

Returns the current auth instance derived from module config. Accepts an explicit override via options.

**Signature**

```typescript
function useBoxAuth(options?: {
  authType?: BoxAuthType
  config?: UseBoxAuthConfig<BoxAuthType>
  tokenStorage?: TokenStorage
}): Authentication | undefined
```

**Returns** `Authentication | undefined`

**Example**

```typescript
const auth = useBoxAuth()
const client = new BoxClient({ auth: auth! })
```

---

### `useBoxCcgAuth(config?, tokenStorage?)`

Returns a `BoxCcgAuth` instance configured with Client Credentials Grant.

**Signature**

```typescript
function useBoxCcgAuth(
  config?: CcgConfig | CcgConfigInput,
  tokenStorage?: TokenStorage
): BoxCcgAuth
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `config` | `CcgConfig \| CcgConfigInput` | No | CCG config override. Uses `runtimeConfig.box.ccg` when omitted. |
| `tokenStorage` | `TokenStorage` | No | Custom token storage implementation. |

**Example**

```typescript
const ccgAuth = useBoxCcgAuth({
  clientId: 'CLIENT_ID',
  clientSecret: 'CLIENT_SECRET',
  enterpriseId: 'ENTERPRISE_ID'
})
```

---

Returns a `BoxJwtAuth` instance.

**Signature**

```typescript
function useBoxJwtAuth(
  config?: JwtConfig | JwtConfigInput,
  tokenStorage?: TokenStorage
): BoxJwtAuth
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `config` | `JwtConfig \| JwtConfigInput` | No | JWT config override. Uses `runtimeConfig.box.jwt` when omitted. |
| `tokenStorage` | `TokenStorage` | No | Custom token storage implementation. |

**Example**

```typescript
const jwtAuth = useBoxJwtAuth() // reads NUXT_BOX_JWT_* env vars

function useBoxOAuth(

```

**Parameters**

### `useBoxAuthConfig(auth?, config?, tokenStorage?)`

Returns the resolved, fully merged auth config object for the given auth type. Reads from `runtimeConfig` when config is omitted.

**Signature**

```typescript
function useBoxAuthConfig<T extends BoxAuthType>(
  auth?: T,
  config?: UseBoxAuthConfigInput<T>,
  tokenStorage?: TokenStorage
): UseBoxAuthConfig<T>
```

**Parameters**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth` | `BoxAuthType` | No | Auth type — `'dev'`, `'ccg'`, `'jwt'`, or `'oauth'`. Falls back to `runtimeConfig.public.box.auth`. |
| `config` | `UseBoxAuthConfigInput<T>` | No | Config input override. |
| `tokenStorage` | `TokenStorage` | No | Token storage override. |

**Returns** `UseBoxAuthConfig<T>` — a concrete config class (`CcgConfig`, `JwtConfig`, `OAuthConfig`, or `DeveloperTokenConfig`).

**Example**

```typescript
// Read the active CCG config as resolved by the module
const ccgConfig = useBoxAuthConfig('ccg')
console.log(ccgConfig.enterpriseId)
```
