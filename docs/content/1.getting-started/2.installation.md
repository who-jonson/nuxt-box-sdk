## Install the module

Add `nuxt-box-sdk` to your project using your preferred package manager.

::code-group

```bash [pnpm]
pnpm add nuxt-box-sdk
```

```bash [npm]
npm install nuxt-box-sdk
```

```bash [yarn]
yarn add nuxt-box-sdk
```

::

## Register the module

Add `nuxt-box-sdk` to the `modules` array in your `nuxt.config.ts`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-box-sdk'],
})
```

## Configure for local development

For local development, a developer token is the fastest way to get started. Generate one from the [Box Developer Console](https://app.box.com/developers/console) under your app's **Configuration** tab.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-box-sdk'],
  box: {
    developer: {
      token: process.env.BOX_DEVELOPER_TOKEN,
    },
  },
})
```

Create a `.env` file in your project root and add your token:

```bash [.env]
BOX_DEVELOPER_TOKEN=your_developer_token_here
```

::warning
Developer tokens expire after 60 minutes and are intended for local development only. For production, configure a [CCG, JWT, or OAuth auth strategy](/guide/authentication).
::

## Fetch your first file

Once the module is installed and configured, the manager composables are auto-imported. The following example lists the items in your Box root folder (folder ID `'0'`).

```vue [pages/index.vue]
<script setup lang="ts">
const foldersManager = useBoxFoldersManager()

const { data: rootFolder } = await foldersManager
  .withAsyncData()
  .getFolderItems('0', { fields: ['name', 'type', 'size'] })
</script>

<template>
  <ul>
    <li v-for="item in rootFolder?.entries" :key="item.id">
      {{ item.name }} ({{ item.type }})
    </li>
  </ul>
</template>
```

`withAsyncData()` returns a Proxy that wraps every manager method in Nuxt's `useAsyncData`, so data fetching is SSR-compatible and deduplication is handled automatically.

::tip
By default, all Box managers are included in the build. To reduce bundle size, configure `managers.include` with only the managers your app needs. See the [Configuration guide](/guide/configuration) for details.
::
